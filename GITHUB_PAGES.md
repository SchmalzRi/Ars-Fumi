# Updating GitHub Pages to Ars Fumi 0.5.0

1. Export a JSON backup from Settings.
2. Replace the repository files with all files from this folder.
3. Wait for GitHub Pages to deploy.
4. Open the regular Pages URL in Safari and refresh once.
5. Fully close and reopen the Home Screen app.
6. Verify **Installed build: Ars Fumi 0.5.0** in Settings.

The storage key and schema remain compatible with 0.4.4.
