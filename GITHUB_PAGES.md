# Update Ars Fumi on GitHub Pages

1. Extract the ZIP.
2. Copy the contents of the `ars_fumi_0_2_1` folder into the root of your existing Ars Fumi repository.
3. Replace the previous files and commit the change.
4. Wait for the Pages deployment to finish.
5. Open the site in Safari and refresh it once.
6. Fully close and reopen the installed Home Screen app. Refresh again if the old `0.2` label is still visible.

The local-storage key and schema are unchanged, so existing sessions, catalogues, and settings remain available at the same GitHub Pages address.
