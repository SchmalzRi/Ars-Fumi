# GitHub Pages update

1. Export a JSON backup from the currently installed Ars Fumi build.
2. Replace the repository-root files with the contents of this folder.
3. Commit and wait for GitHub Pages to redeploy.
4. Open the normal Pages URL in Safari and refresh once.
5. Fully close and reopen the Home Screen app.
6. Confirm **Ars Fumi 0.3.0** under Settings.

The local-storage key and data schema remain compatible with 0.2.2. Existing records should remain in place at the same Pages URL. Cover photos are stored locally and included in JSON exports; use sensible image sizes because browser storage is finite.
