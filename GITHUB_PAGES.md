# Updating GitHub Pages to Ars Fumi 0.4.4

1. Export a JSON backup from the current app as a precaution.
2. Replace the repository files with the contents of this folder.
3. Commit and wait for GitHub Pages to deploy.
4. Open the normal Pages URL in Safari and refresh once.
5. Fully close and reopen the Home Screen app if it remains cached.
6. Confirm **Installed build: Ars Fumi 0.4.4** in Settings.

The storage schema is unchanged, so existing sessions, recipes, people, photos, and catalogues remain compatible.
