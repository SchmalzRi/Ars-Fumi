# Updating GitHub Pages to Ars Fumi 0.6.4 1. Export a JSON backup from the currently installed Ars Fumi build. 2. Extract `Ars_Fumi_0.6.4_Brand_Flavor_Update.zip`. 3. Replace the repository-root files with the contents of the extracted `ars_fumi_0_6_4` folder. 4. Commit and wait for GitHub Pages to redeploy. 5. Open the Pages URL in Safari and refresh once. 6. Fully close and reopen the Home Screen app. 7. Confirm **Ars Fumi 0.6.4** is shown in the app. The storage key and schema remain unchanged, so existing data at the same Pages URL should remain available.
