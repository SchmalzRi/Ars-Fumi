# Ars Fumi 0.2.0

- Retuned Light Mode with muted grey-blue backgrounds, softer cards, and stronger scientific blue accents.
- Increased the visibility of the People module's green visual identity.
- Added an equipment catalogue manager to Settings.
- Added editing of equipment names and types.
- Added equipment removal with confirmation and safe default reassignment.
- Prevented removal of the final item in a required equipment category.
- Added equipment creation from Settings without changing the current Science default.
- Kept in-Science `Add New` behavior as add-and-select.
- Kept the existing v0.1 local-storage key so browser data carries forward.

# Ars Fumi 0.1.0

- Science is the default/home module.
- Normal and Senku Mode workflows.
- Single and Mix tobacco workflows.
- Side-by-side tobacco/percentage mix rows.
- Persistent Hookah, Bowl, HMD, and Coal catalogues with in-place Add New.
- One/two-hose toggle and Dense, Fluffy, Light, Hybrid pack styles.
- Eight 1–10 sliders with editable numeric inputs and Aroma N/A.
- Optional Senku variables and standard/custom coal strategy.
- Session, Experiment, Candidate, and Recipe save states with recipe-family links.
- Local persistence, recent records, JSON import/export, demo records, light/dark themes.
- Recipes, People, Statistics, and Settings visual shells.
